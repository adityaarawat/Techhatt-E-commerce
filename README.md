# 🛒 TechHaat - E-Commerce App

**TechHaat** is a modern, full-featured e-commerce web application built with **React**, **Tailwind CSS**, and **Vite**. It allows users to browse products, add to cart, and enjoy a smooth shopping experience.  

---

## 🚀 Features

- 🖥️ **Responsive Design**: Works perfectly on desktop, tablet, and mobile  
- 🔐 **Authentication**: Secure login and signup using Clerk  
- 🛍️ **Shopping Cart**: Add, remove, and view items in your cart  
- 💳 **Checkout Ready**: Integration-ready checkout flow  
- 🎨 **Slick UI**: Modern, clean design with Tailwind CSS  
- ⚡ **Fast & Smooth**: Powered by React and Vite for lightning-fast performance  
- 📦 **Product Carousel**: Beautiful product sliders using react-slick  
- 🔔 **Notifications**: Toast messages for actions using react-toastify  

---

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Vite  
- **Routing**: React Router DOM  
- **Icons**: React Icons, Lucide React  
- **State Management**: Built-in React state (can integrate Redux if needed)  
- **HTTP Requests**: Axios  
- **Authentication**: Clerk React
